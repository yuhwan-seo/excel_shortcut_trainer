# excel_shortcut_trainer — v2（F4・書式コピー追加）

Excel のショートカットを、Excel 風の画面でセルを選択し、実際にキー入力しながら練習する日本語教材です。Windows 版 Excel の操作を想定した、ブラウザ上の学習用シミュレーターです。Excel 本体や Node.js のインストールは不要です。

**今回の追加：7問。全45問 × 5回＝225問。** 1～3回目は順番に、4～5回目は未達成の問題をランダムに練習します。

## 追加した練習

### Lesson 2：F4 による参照形式の切り替え（4問）

D3 を選択して F2 で数式編集を開始し、F4 で対象の参照を切り替え、最後に Enter で確定します。正しい数式を確定するまで正解にはなりません。

| 練習 | 開始時の数式 | 目標の数式 | F2 の後の操作 |
| --- | --- | --- | --- |
| 絶対参照に変更 | `=B3*C3` | `=$B$3*C3` | F4 → Enter |
| 行だけを固定 | `=B3*C3` | `=B$3*C3` | F4 を2回 → Enter |
| 列だけを固定 | `=B3*C3` | `=$B3*C3` | F4 を3回 → Enter |
| 相対参照に戻す | `=$B$3*C3` | `=B3*C3` | F4 を3回 → Enter |

切り替わる順序は `B3 → $B$3 → B$3 → $B3 → B3` です。現在の数式・目標・F4 を押した回数と、右1列・下1行へコピーした場合の式を表示します。

この教材では F2 の後に先頭の参照を自動選択します。実際の Excel では、数式内の変更したい参照にカーソルを置くか、その参照を選択してから F4 を押します。本教材でも、数式バーの参照をクリックして変更対象を選び直せます。

### Lesson 4：F4 による書式操作の繰り返し（2問）

直前の書式設定は実行済みの場面から始まります。指定された別のセルを選択して F4 を押します。

- 黄色の塗りつぶしを D3 に繰り返す。値「960」は保持します。
- 太字の設定を D4 に繰り返す。値「760」は保持します。

**F4 は直前の操作の繰り返しであり、コピー元の書式全体をコピーする操作ではありません。** この違いが見えるように、直前の操作以外の書式は適用しない場面にしています。

### Lesson 4：書式だけをコピー・貼り付け（1問）

1. コピー元 B3 を選択して **Ctrl + C**。
2. 貼り付け先 D5 を選択して **Ctrl + Alt + V**。
3. 表示された「形式を選択して貼り付け」で **T** を押し、「書式」を選択。
4. **Enter** で確定。

黄色の塗りつぶし・青い文字・太字・下線をコピーし、D5 の値「900」は変更しません。コピー元、貼り付け先、貼り付け形式、確定までを判定します。通常の Ctrl + V や「すべて」「値」の選択では正解になりません。

クリップボードは教材内で模擬しています。実際のパソコンのクリップボードを読み取るものではありません。

## 使い方

ZIP を展開し、同じフォルダに `index.html`、`app.js`、`style.css` がある状態で `index.html` をブラウザで開きます。授業でURLを配布する場合は、GitHub Pages 用のファイルとしてそのまま利用できます。公開手順は `GITHUB_PAGES_SETUP.md` を参照してください。

問題文に従ってセルをクリックし、ショートカットを入力します。「入力をリセット」でその問題の場面をやり直し、「動きをもう一度見る」で正解後の動作を確認できます。5回すべて終わると完了メッセージと「画面キャプチャー」ボタンを表示します。保存した PNG を Teams の課題に提出する従来の流れを維持しています。

Ctrl + T などのキーがブラウザ自身に使われる場合は、右上の「ショートカット練習モード」を利用してください。キーの捕捉可否は端末やブラウザに依存します。macOS 版 Excel のショートカット体系への切り替え機能はありません。

## 既存公開ページの更新と履歴

既存リポジトリの同じ場所に、このZIPの中身を上書きしてください。**`index.html`、`app.js`、`style.css` は必ず一緒に更新**します。古いHTMLと新しいJSなどを混在させないでください。HTMLのCSS・JS参照には今回の版の識別子を付けています。

既存の履歴用キー `excelShortcutTrainer_GITHUB_PAGES_v1` は変更していません。同じブラウザ・同じ公開URLで、保存データが残っていれば旧版の正解履歴を引き継ぎます。ブラウザのデータ削除、別端末、別ブラウザや公開先変更に伴う引き継ぎは保証しません。ローカルファイルの保存動作もブラウザに依存します。

追加問題は各回で未達成になります。そのため、更新後に進捗率が下がったり、前の練習回へ戻ったりするのは正常です。旧版の38問を5回とも完了済みの場合は、以前の190問を保持し、追加7問 × 5回＝35問を練習します。「進捗をリセット」は既存履歴も消すため、引き継ぎたい場合は押さないでください。

保存できない環境では画面に注意を表示し、そのページを開いている間だけ練習できます。
